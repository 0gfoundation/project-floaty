This repo contains only new code (the dashboard hub, pages and simulator). The face images in
`dashboard/static/faces/` are renders of the project's own procedural face (Mochi-Pixel), drawn by the robot
firmware fork and released here under this repo's MIT license. The admin page is ported from the
project's own robot brain. All demo data in `data/` is made up. The repo ships no code from the projects above. The robot-side telemetry module will be published with the firmware fork, keeping every upstream license.
